Google Fit Setup & Credentials

To log data into Google Fit, Google requires a free OAuth Client ID from Google Cloud Console. Follow these quick steps:

1
Open Google Cloud Console

Go to Google Cloud Console and create a new project named StepHack.

2
Enable the Fitness API

Go to APIs & Services → Library, search for Fitness API, and click Enable.

3
OAuth Consent Screen

Go to OAuth consent screen → Select External → Fill App name (StepHack) & email → Under Test users, add your Google account email.

4
Create OAuth 2.0 Client ID

Go to Credentials → Create Credentials → OAuth client ID:

  • Application type: Web application
  • Authorized redirect URIs:
    http://localhost:3000/auth/callback
    http://192.168.x.x:3000/auth/callback
5
Paste Credentials Below
