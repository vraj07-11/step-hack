# StepHack

A web application that logs walking sessions into Google Fit with realistic cadence distribution, simulated hardware pedometer streams, and synchronized distance and calorie metrics.

Live deployment: [https://step-hack.onrender.com](https://step-hack.onrender.com)

---

## Overview

When activity is added manually in fitness trackers, it is often recorded as a single summary record without granular sensor intervals. Many fitness trackers, sync tools, and third-party integrations ignore these summary entries because they lack hardware sensor data.

StepHack resolves this by writing data directly through the Google Fitness REST API using the same format generated by mobile device hardware:

- **Raw Hardware Sensor Streams**: Writes records with `type: "raw"` and `device.type: "phone"` (supports device profiles such as Google Pixel, Samsung Galaxy, and OnePlus).
- **Time-Distributed Intervals**: Distributes steps across realistic 30-second intervals with natural cadence variance, warmup/cooldown curves, and micro-pauses.
- **Synchronized Metrics**: Simultaneously writes matching distance (`com.google.distance.delta`), calories (`com.google.calories.expended`), and activity segments (`com.google.activity.segment`, Activity Type 7 - Walking).
- **Stateless Multi-User Support**: User authentication tokens are stored securely in encrypted HTTP-only browser sessions, avoiding persistent server-side token storage.

---

## Features

- **Cadence Calibration**: Configurable walking pace slider (80 to 140 steps per minute) with auto-fit pacing recommendations.
- **Timestamp Configuration**: Choose past walk end times, retroactive dates, or current time.
- **Device Profile Selection**: Emulate specific phone hardware sensor metadata (Google Pixel 8 Pro, Samsung Galaxy S24 Ultra, OnePlus 12, etc.).
- **Live Sync & History**: View today's total steps, historical logs, and real-time Google Fit status updates.
- **PWA Ready**: Installable to Android and iOS home screens as a standalone Progressive Web App.

## Getting Started

### Prerequisites

- Node.js 18.0 or higher
- npm 9.0 or higher
- A Google Cloud project with the **Fitness API** enabled

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/vraj07-11/step-hack.git
   cd step-hack
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Create a `.env` file in the project root:
   ```env
   PORT=3000
   NODE_ENV=development
   GOOGLE_CLIENT_ID=your_oauth_client_id.apps.googleusercontent.com
   GOOGLE_CLIENT_SECRET=your_oauth_client_secret
   REDIRECT_URI=http://localhost:3000/auth/callback
   SESSION_SECRET=your_random_session_secret_key
   ```

4. Start the application:
   ```bash
   npm start
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Google Cloud OAuth Setup

To run your own instance:

1. Open the [Google Cloud Console](https://console.cloud.google.com/) and create a project.
2. Navigate to **APIs & Services > Library**, search for **Fitness API**, and enable it.
3. In **APIs & Services > OAuth consent screen**:
   - Set User Type to **External**.
   - Provide an application name, user support email, and developer contact email.
   - Under **Scopes**, add:
     - `https://www.googleapis.com/auth/fitness.activity.write`
     - `https://www.googleapis.com/auth/fitness.activity.read`
     - `https://www.googleapis.com/auth/fitness.location.write`
     - `https://www.googleapis.com/auth/fitness.location.read`
     - `https://www.googleapis.com/auth/fitness.body.write`
     - `https://www.googleapis.com/auth/fitness.body.read`
     - `https://www.googleapis.com/auth/userinfo.profile`
     - `https://www.googleapis.com/auth/userinfo.email`
4. In **APIs & Services > Credentials**:
   - Create an **OAuth 2.0 Client ID** with type **Web application**.
   - Add your callback URL to **Authorized redirect URIs** (e.g. `http://localhost:3000/auth/callback` or `https://your-domain.com/auth/callback`).
5. Copy the Client ID and Client Secret into your `.env` configuration.

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/health` | Health check endpoint for monitoring bots |
| `GET` | `/api/status` | Returns authentication state and session status |
| `GET` | `/api/auth/url` | Generates Google OAuth consent URL |
| `GET` | `/auth/callback` | OAuth redirect callback handler |
| `POST` | `/api/auth/logout` | Clears user session and revokes tokens |
| `GET` | `/api/today-steps` | Retrieves aggregated step counts for today from Google Fit |
| `POST` | `/api/sync` | Generates intervals and commits step session to Google Fit |
| `GET` | `/api/history` | Returns recent sync history stored in user session |
